# P2G-PEM-Sizing

재생에너지 잉여전력을 수소로 바꾸는 **P2G(Power-to-Gas)** 설비를 모델링하고, 투자비와 운영비를 반영해 **PEM 수전해기·수소저장탱크의 최적 용량**을 산정하는 탐구 프로젝트.

> 지도: 김성열 교수 (한양대 전기공학과, P2G/P2X 스마트그리드) · 방향: 전기화학 + AI

## 구도

```
재생에너지 발전량 ──▶ PEM 수전해 ──▶ 수소저장탱크 ──▶ 수소 수요
                       (전기화학 모델)   (24시간 수지)
                              └──── 투자비·운영비 → 최적 용량 (MILP) ────┘
```

1. **기본 모델**: 일정 효율의 PEM + 탱크 모델로 24시간 생산·수요·저장량을 계산하고, 용량별 비용을 비교해 최적 용량을 구한다.
2. **전기화학 심화 모델**: 막 열화, 산소 쪽 기체 동역학, OER 기작 등을 넣어, 정효율 가정이 수소 생산량 분포를 얼마나 왜곡하는지 확인한다.
3. **불확실성 분석**: 기상, 전기화학 파라미터, 기작 선택, 수명 시점의 기여를 Sobol 지수로 비교한다.
