# P2G-PEM-Sizing

재생에너지 잉여전력을 수소로 바꾸는 **P2G(Power-to-Gas)** 설비를 모델링하고, 투자비와 운영비를 반영해 **PEM 수전해기·수소저장탱크의 최적 용량**을 산정하는 탐구 프로젝트.

> 지도: 김성열 교수 (한양대 전기공학과, P2G/P2X 스마트그리드) · 방향: 전기화학 + AI

## 1. 배경

- 전력은 생산과 소비가 항상 같아야 한다. 어긋나면 주파수가 흔들려 정전으로 이어질 수 있다.
- 제어가 어려운 재생에너지(태양광·풍력)가 늘면서 문제가 부족이 아니라 **과잉 공급**이 되었다. 지금은 재생에너지 출력을 제한해 균형을 맞추고, 이때 버려지는 전력이 **잉여전력**이다.
- 호남권처럼 재생에너지가 몰린 지역은 계통 수용 여유가 부족해 지역 단위 생산·소비가 필요하다.
- 잉여전력 저감 수단: 수요반응(DR, 플러스 DR) / ESS / 통합에너지시스템(IES)
- **P2G**는 IES의 한 방법이다. 잉여전력으로 물을 전기분해해 그린수소를 만들고, 수소 스테이션에 공급하거나 연료전지로 전기·열을 다시 만든다.
- 하루 전 발전계획에는 수요와 재생 발전량 예측이 쓰이고, 시간 패턴 학습에 유리한 LSTM을 AI 방법으로 소개한다.

## 2. 학습 목표

재생에너지 발전량과 수소 수요를 고려해 PEM 수전해기와 수소저장탱크를 모델링하고, 투자비와 운영비를 반영한 최적 용량을 산정한다.

## 3. 학습 순서

1. 단위와 수전해 원리 (kW와 kWh, kg와 kg/h, 전력소비 원단위, 저장량과 저장용량, 투자비의 연간 환산)
2. PEM 셀 모델 (`PEMEL_modeling1`)
3. 수소 저장탱크 (`PEMEL_modeling2`)
4. 24시간 생산·수요·저장량 계산
5. 목적함수와 제약조건
6. 용량별 비용 비교 및 최적화
7. 발전량·수요 변화 분석

## 4. 모델링 원칙

- 처음에는 **일정 효율 모델**로 용량 산정을 한다. 상세 동특성(열·전기화학) 모델과 용량 산정용 모델은 구분한다.
- 탱크 저장량은 `저장량(t) = 저장량(t-1) + 생산량(t) - 수요량(t)`의 누적으로 계산하고, 초기·종료 저장량과 용량 한계를 명시한다.
- 첫 범위는 `재생에너지 → PEM 수전해 → 수소탱크 → 수소 수요`까지로 한정한다. 연료전지·열·배터리와 상세 열 모델은 심화 과제로 둔다.
- 논문 구현은 Python 기반 MILP다. MATLAB을 쓸 경우 Python으로 만든 데이터를 가져다 쓴다.

## 6. 전기화학 심화 모델 (확장)

일정 효율 모델을 대학원 전기화학 수준으로 확장하는 설계다. 개념이 어렵다는 이유가 아니라 **연구 질문(정효율 가정이 수소 생산량 분포를 얼마나 왜곡하는가)의 답을 바꾸는지**를 직접 계산해 채택 여부를 정했다.

- 기준 모델: 80 °C, 캐소드 30 bar, Nafion 117, 재결합률 80 %, 안전 기준 수소 2 %
- 채택 기준: 시간 해상도 1시간의 수소 생산량 분포(평균, 표준편차, 생산 0 확률)를 1 % 이상 바꾸는가. 바꾸지 않으면 그 사실을 계산으로 보이고 제외 근거로 기록한다.

| 항목 | 핵심 개념 | 계산한 영향 | 판정 |
|---|---|---|---|
| 막 화학 열화·크로스오버 되먹임 | H₂O₂ 생성, 펜톤 반응, PFSA 사슬 분해 | 막 178→125 µm에서 흐린 날 생산 0 확률 23 %→35 % (100 µm에서 44 %) | 채택(핵심) |
| 산소 쪽 기체 동역학·안전 한계 | 완전 혼합 탱크 물질수지, 기체 체류시간 | 수소 2 % 도달까지 6분~2시간 이상 | 채택(핵심) |
| OER 미시동역학 | 중간체 피복률, 타펠 기울기 전이 | 2 A/cm²에서 최대 45 mV 차이, 흐린 날 평균 왜곡 −6.5 %→−9.2 % | 채택 |
| 촉매층 다공성 전극 | de Levie 전송선, Newman 이론 | 정격 효율 1~3 %p 감소 | 채택(보조) |
| EIS·DRT 모델 형태 식별 | Kramers–Kronig, 이완시간 분포 | 분극곡선만으로는 기작 구별 불가(맞춤 오차 4~32 mV) | 채택(포텐시오스탯 사용 시) |
| 정지·재기동 시 Ir 산화상태 | Ir 용출 안정성 | 장기 효과, 시나리오 분석만 | 확장 과제 |
| 전류 의존 수소 과포화 | 헨리 법칙 | 30 bar에서 0~1.6 %p | 상압 비교 때만 |
| 이중층·의사축전, 실기체 퓨가시티 | 이중층, 비리얼 방정식 | 각각 무시 가능(0.002 %, 0.2 mV) | 제외 |

**핵심 결론**

- 막이 얇아지면 수소 투과가 늘고 최소부하가 오른다(178 µm 6.5 % → 100 µm 12.2 %). 그래서 같은 기상 예측이라도 수명 시점에 따라 생산 분포가 달라진다. 확률 최적화 입력을 신품 기준과 수명 말기 기준으로 나눈다.
- 최소부하 아래에서도 산소 쪽 수소 농도는 서서히 오르므로, 안전 제약은 순간값이 아니라 **시간 결합 제약**으로 쓴다. 순간 차단으로 두면 생산 0 확률을 과대평가할 수 있다.
- OER 기작 선택(단일 전달계수 vs 2단계 기작)은 중간 전류 자료만으로 정할 수 없으므로 이산 불확실성 요인으로 둔다.

**통합 모델**: 상태변수 4개(스택 온도 T, 산소 쪽 수소 몰분율 x, 막 두께 δ, 애노드 활성 면적[확장])와 대수 방정식 1개(전류밀도 j)로 이루어진 미분–대수 방정식 계. 불확실성 요인은 기상(연속), 전기화학 파라미터(연속), 기작 선택(이산), 수명 시점(시나리오) 네 가지이고, Sobol 지수로 수소 생산량 분산과 생산 0 확률에 대한 기여를 비교한다.

**구현 순서**

| 순서 | 내용 | 도구 | 난이도 |
|---|---|---|---|
| 1 | 분리기 물질수지 추가, 생산 0 확률 재계산 | scipy `solve_ivp` | 하 |
| 2 | 막 박화 되먹임, 수명 시나리오별 분포 | 해석해 + 문헌 FER | 중 |
| 3 | 2단계 기작, 기작 선택을 불확실성 요인으로 포함 | scipy `least_squares` | 중 |
| 4 | 촉매층 경계값 문제 | scipy `solve_bvp` | 중상 |
| 5 | 통합 분산 분해(기상·파라미터·기작·수명) | SALib | 중 |
| 6 | EIS·DRT (포텐시오스탯 사용 시) | impedance.py, pyDRTtools | 상 |

## 7. 주의사항

- 2024년 논문의 식 (8)은 운전시간 **상한**인데 설명은 **하한**으로 적혀 있다(오타). 구현할 때 식을 기준으로 한다.
- 논문별로 단위 체계가 다르므로 식을 옮길 때마다 단위를 먼저 맞춘다.
- 전기화학 심화 모델의 영향 크기는 가상 기상 분포와 기준 모델 가정에서 계산한 값이다. 실측 자료로 검증하기 전에는 결론이 아니라 설계 근거로 쓴다. 참고문헌 서지는 기억과 검색 기록을 바탕으로 적었으므로 제출 전 원문과 대조한다.
