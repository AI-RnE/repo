# P2G-PEM-Sizing

재생에너지 잉여전력을 수소로 바꾸는 **P2G(Power-to-Gas)** 설비를 모델링하고, 투자비와 운영비를 반영해 **PEM 수전해기·수소저장탱크의 최적 용량**을 산정하는 탐구 프로젝트. 핵심은 정효율 가정을 버리고, **기상 예측의 불확실성이 부하의존 전해조를 거쳐 수소 생산량 분포로 전달되는 과정**을 다루는 것이다.

> 지도: 김성열 교수 (한양대 전기공학과, P2G/P2X 스마트그리드) · 방향: 전기화학 + AI · 상태: 계획·모델 설계 단계 (코드와 실험은 아직 없음)

## 연구 질문

정효율 가정 대신 부하에 따라 효율이 달라지는 전해조 모델을 쓰면, 기상 기반 확률 예측에서 나오는 수소 생산량의 **평균, 표준편차, 생산 0 확률**이 얼마나 달라지는가.

## 전체 구도

```
(1) 기상 예보 ─▶ 재생에너지 출력의 확률분포·시나리오
(2) 출력 P ─▶ 전류밀도 j 역산            P = N_cell · A · j · V_cell(j)
(3) j ─▶ 전압·패러데이 효율 ─▶ 수소 생산률
(4) 열·분리기·막 상태의 시간 적분
(5) 시나리오별 수소 생산량 ─▶ 확률 최적화(MILP) 입력 ─▶ 최적 용량
```

| 모델 | 내용 |
|---|---|
| M0 정효율 | 수소 = ηP / HHV. 비교 기준 |
| M1 등가회로 | V = e_rev + I·R_i |
| M2 반경험 전기화학 | 가역전압 + 활성화(asinh) + 옴 + 농도 손실, 패러데이 효율. **본 모델** |
| M3 동적 | M2 + 열수지, 산소 쪽 분리기 물질수지, 막 박화, 탱크 |

## 접근

1. **소형 PEM 셀 실험은 절차 검증용**이다. 실험실 셀의 값을 30 bar 스택에 그대로 쓰지 않고, 파라미터 추정 절차가 얼마나 정확한지 정량화하는 데 쓴다. 스택 값은 문헌 사전분포로 둔다.
2. 검증된 절차로 얻은 **파라미터 사후분포**를 기준 스택(80 °C, 30 bar, Nafion 117) 모델에 넣어 수소 생산 분포를 계산한다.
3. 기상·전기화학 파라미터·기작 선택·수명 시점의 기여를 **Sobol 지수**로 분해한다.
4. 비선형 곡선을 **구간별 선형 근사**해 MILP로 넘긴다.

## 지금까지 정리된 핵심 결과 (가상 기상 분포·기준 모델 가정의 계산값)

- 막이 178 → 125 µm로 얇아지면 흐린 날 생산 0 확률이 **23 % → 35 %**(100 µm에서 44 %)로 오른다. 수명 시점을 불확실성 요인으로 넣어야 한다.
- 산소 쪽 수소 농도가 2 %에 도달하는 시간은 기체 체류에 따라 **6분~2시간 이상**이다. 최소부하 순간 차단 가정은 생산 0 확률을 과대평가하므로 안전 제약은 **시간 결합 제약**으로 쓴다.
- OER 기작 선택에 따라 2 A/cm² 과전압이 **최대 45 mV** 달라진다. 기작은 이산 불확실성 요인이다.
- 일반적으로 $E[f(P)]\ne f(E[P])$이므로 평균 발전량만 모델에 넣으면 수소 평균이 틀어진다. 보정 크기는 분산과 곡률에 의존한다.
