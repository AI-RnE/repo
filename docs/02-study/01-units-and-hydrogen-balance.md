# 단위와 수소 수지 기초

학습 순서의 1단계다. 모델링에 들어가기 전에 단위와 수지 개념을 맞춘다.

## 단위 구분

| 개념 | 단위 | 비고 |
|---|---|---|
| 전력(출력) | kW | 순간값. 수전해기 입력 $P$ |
| 전력량 | kWh | $\int P\,dt$ |
| 수소 질량 | kg | 저장량, 누적 생산량 |
| 수소 생산률 | kg/h | 시간당 질량 유량 |
| 전력소비 원단위 | kWh/kg-H₂ | 효율의 역수에 해당 |
| 저장량 vs 저장용량 | kg | 저장량은 시점별 상태, 저장용량은 탱크의 상한 |

## 에너지–수소 환산

- 수소 고위발열량 HHV는 39.4 kWh/kg을 쓴다. 열중성 전압은 1.48 V다.
- 일정 효율 모델(M0): $H=\eta P/\mathrm{HHV}$
- 예시(형식 확인용): 효율 0.7로 1 MWh를 투입하면 $1000\times0.7/39.4\approx17.8$ kg
- 연료전지로 되돌릴 때는 kg-H₂ × HHV × 연료전지 효율 = kWh

## 24시간 수소 수지

$$S_t=S_{t-1}+H_{\mathrm{prod},t}-H_{\mathrm{demand},t},\qquad 0\le S_t\le S_{\max}$$

- 초기 저장량 $S_0$와 종료 조건(예: $S_T\ge S_0$)을 명시한다.
- 생산량과 수요량의 시간 단위를 맞춘다(kg/h × 시간 간격).

## 투자비의 연간 환산

설비 투자비는 연간 비용으로 바꿔 운영비와 같은 기준에서 비교한다. 이자율 $r$, 수명 $n$년일 때 자본회수계수를 쓴다.

$$\mathrm{CRF}=\frac{r(1+r)^n}{(1+r)^n-1},\qquad \text{연간 투자비}=\text{투자비}\times\mathrm{CRF}$$

용량 최적화의 목적함수는 `연간 투자비(수전해기 + 탱크) + 운영비`로 둔다. 구체적인 최적화 형식은 [`../08-optimization/01-milp-interface.md`](../08-optimization/01-milp-interface.md).

## 수전해 원리 (요약)

- 물을 전기분해해 캐소드에서 수소, 애노드에서 산소를 만든다. PEM 수전해는 양성자 교환막(Nafion 등)을 쓴다.
- 패러데이 법칙으로 전류가 수소 몰 생산 속도와 연결된다: $\dot n_{H_2}=\eta_F\,jA/(2F)$
- 셀 전압은 가역전압에 활성화·옴·농도 과전압이 더해진다. 자세한 식은 [`../04-modeling/02-cell-voltage-and-efficiency.md`](../04-modeling/02-cell-voltage-and-efficiency.md).
