# 학습 목표와 순서

## 목표

재생에너지 발전량과 수소 수요를 고려해 PEM 수전해기와 수소저장탱크를 모델링하고, 투자비와 운영비를 반영한 **최적 용량**을 산정한다.

## 권장 순서

| 단계 | 내용 | 자료 |
|---|---|---|
| 1 | 단위와 수전해 원리 | [`01-units-and-hydrogen-balance.md`](01-units-and-hydrogen-balance.md) |
| 2 | PEM 셀 모델 (등가회로: 전압·전류·수소 생산량) | modeling1 |
| 3 | 수소 저장탱크 (저장량·압력) | modeling2 |
| 4 | 24시간 생산·수요·저장량 계산 | 수지 식 |
| 5 | 목적함수와 제약조건 | 2023·2024 국문 논문 |
| 6 | 용량별 비용 비교 및 최적화 | 2024 국문 논문 |
| 7 | 발전량·수요 변화 분석 | 시나리오 |

## 범위

- **첫 실습**은 `재생에너지 → PEM → 탱크 → 수소 수요`로 한정한다.
- 연료전지, 열, 배터리, 상세 열 모델은 심화로 둔다. 펌프·냉각 등 BOP 소비전력을 넣은 시스템 효율도 심화다([`../04-modeling/04-balance-of-plant.md`](../04-modeling/04-balance-of-plant.md)).
- 상세 동특성 모델과 **용량 산정용 모델은 구분**한다. 처음에는 일정 효율 모델로 용량 산정을 먼저 수행한다.
- 탱크는 생산량 − 수요량의 누적으로 계산하고, 초기·종료 저장량과 용량 한계를 명시한다.

## 구현 환경

- 논문 구현은 Python 기반 MILP다. MATLAB을 쓸 경우 Python으로 만든 데이터를 가져다 쓴다.

## 주의사항

- 2024년 논문의 식 (8)은 운전시간 **상한**인데 설명은 **하한**으로 적혀 있다(오타). 구현할 때 식을 기준으로 한다.
- 논문별로 단위 체계가 다르므로 식을 옮길 때마다 단위를 먼저 맞춘다.
- 초심자를 위해 단위, 수소 수지, 최적화 기초는 따로 보충한다.
