# 시스템 효율과 BOP(주변 설비) 소비전력 (심화 확장)

현재 M0~M3의 효율은 **스택(셀)** 기준이다. 실제 설비는 물 순환 펌프, 냉각·보온, 전력변환(정류기·DC-DC), 제어 전원을 쓰고, 이 전력은 수소를 만들지 않는다. 이를 넣어 **시스템 전체 효율**을 보는 확장이다. 첫 실습 범위(재생에너지 → PEM → 탱크)를 넘는 심화 항목이다([`../02-study/02-learning-path.md`](../02-study/02-learning-path.md)).

## 효율 정의 (혼용 방지)

| 이름 | 식 | 기준 |
|---|---|---|
| 스택 효율 (현재 $\eta_{sys}$) | $\eta_{stack}=\eta_F\,\dfrac{1.48\ \mathrm V}{V_{cell}(j)}$ | 스택 입력 전력 $P_{stack}$, HHV 기준 |
| 시스템 효율 (추가) | $\eta_{total}=\dfrac{\dot n_{H_2}\,\Delta H_{HHV}}{P_{sys}}=\eta_{stack}\,\dfrac{P_{stack}}{P_{sys}}$ | 계통에서 받는 전력 $P_{sys}$, HHV 기준 |

$$P_{sys}=P_{stack}+P_{BOP},\qquad P_{stack}=N_{cell}\,A\,j\,V_{cell}(j),\qquad P_{BOP}=P_{pump}+P_{cool}+P_{conv}+P_{ctrl}$$

($\Delta H_{HHV}=285.8$ kJ/mol은 $1.48\ \mathrm V\times2F$와 같다.) M0와 비교할 때는 어느 효율을 쓰는지 반드시 표시한다.

## BOP 항 모델

| 항 | 모델 | 비고 |
|---|---|---|
| 물 순환 펌프 | 수력 동력 $P_{hyd}=\rho g Q H$, 소비전력 $P_{pump}=P_{hyd}/\eta_{pump}$. 단순화: $P_{pump}=a_p+b_p\,jA$ | 고정(순환 최소 유량) + 전류 비례(급수·열 제거 유량). 가변속 여부는 설계 선택 |
| 냉각 | $P_{cool}=\dot Q_{cool}/\mathrm{COP}$ | $\dot Q_{cool}$는 [상태 방정식](03-state-equations.md)의 열수지에서 온다. 정상상태로 온도를 유지할 때 $\dot Q_{cool}=(V_{cell}-V_{tn})I-(T-T_{amb})/R_{th}$ (0 이상) |
| 보온·가열 | 저부하·정지 중 외기로 빠지는 열을 보상 | 발열이 작을 때 필요할 수 있는 별도 항 |
| 전력변환 | $P_{sys}\ni P_{stack}/\eta_{conv}(P)$ | 변환 효율은 저부하에서 낮다 |
| 제어·계측 | $P_{ctrl}$ 상수 | |
| 대기전력 | 정지($u_t=0$) 중에도 $P_{sb}$ | 제어·보온·최소 순환 |

## 효과

- 고정 소비가 있으므로 부하가 작을수록 $P_{stack}/P_{sys}$가 줄어 **시스템 효율이 더 떨어진다.** 정효율 가정이 놓치는 방향이 하나 더 생긴다.
- **실질 최소부하**가 올라간다. 계통에서 가져와야 하는 최소 전력이 $P_{min}$이 아니라 $(1+b)P_{min}+a$가 된다.
- 최소부하 미달 구간에서 대기전력만 쓰고 수소를 못 만드는 시간이 생긴다. 생산 0 확률은 "스택 기준"과 "계통 기준"을 구분해 보고한다.

## MILP에서의 선형 표현

고정항과 비례항으로 두면 선형이다. $u_t$는 가동 여부 이진변수, $a=a_p+\dots$(고정 합), $b$는 비례 계수 합이다.

$$P_{sys,t}=(1+b)\,P_{stack,t}+a\,u_t+P_{sb}\,(1-u_t)\ \le\ P_{RE,t}$$

[`../08-optimization/01-milp-interface.md`](../08-optimization/01-milp-interface.md)의 조각선형화와 같은 구조에서 상수 항과 계수만 바뀐다.

## 불확실성과 한계

- $a_p$, $b_p$, COP, $\eta_{pump}$, $\eta_{conv}$, $P_{sb}$는 **규모와 설계에 따라 달라지고 값은 문헌·제조사 자료에 의존**한다. 사전 범위는 문헌 조사 후 정한다.
- 소형 실험 셀에는 이런 BOP가 거의 없어 **실험으로 검증할 수 없다.** 실험실의 펌프·항온수조 소비전력은 전력계로 잴 수 있지만 기준 스택을 대표하지 않으므로, "고정 + 비례" 구조가 맞는지 확인하는 정도로만 쓴다.
- BOP 비율은 연속 불확실성 요인으로 추가해 Sobol 분산 분해에 넣는다([`../07-numerics/03-uncertainty-propagation.md`](../07-numerics/03-uncertainty-propagation.md)).

## 비교 설계

같은 시나리오에서 `M3`와 `M3 + BOP`를 나란히 돌려 다음을 본다.

| 지표 | 내용 |
|---|---|
| $\eta_{total}(P)$ 곡선 | 부하에 따른 시스템 효율 |
| 실질 최소부하 | 계통 기준 최소 가동 전력 |
| 생산 0 확률 | 스택 기준 vs 계통 기준 |
| 순수소량 / 계통 전력 | 연간 또는 일별 합계 |
