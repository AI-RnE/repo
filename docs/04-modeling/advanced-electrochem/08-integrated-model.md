# 통합 모델 구조와 구현 순서

## 구조

심화 모델은 **상태변수 4개와 대수 방정식 1개**로 이루어진 미분–대수 방정식(DAE) 계다.

| 구분 | 변수 | 지배 식 | 시간 척도 |
|---|---|---|---|
| 대수 | 전류밀도 $j$ | $P=V_{cell}(j,T,\delta,\text{기작})\cdot j$ (셀·면적 포함) | 즉시 |
| 상태 1 | 스택 온도 $T$ | 열수지(열중성 전압 1.48 V) | 수십 분 |
| 상태 2 | 산소 쪽 수소 몰분율 $x$ | 분리기 물질수지([`02`](02-gas-dynamics-safety.md)) | 수 분~수 시간 |
| 상태 3 | 막 두께 $\delta$ | 화학적 열화 되먹임([`01`](01-membrane-degradation.md)) | 수천 시간 |
| 상태 4 | 애노드 활성 면적(확장) | 정지 횟수 기반 용출([`06`](06-iridium-extension.md)) | 수천 시간 |

시간 척도가 크게 다르므로 **막 두께와 활성 면적은 하루 단위 계산 안에서 상수**로 두고, 수명 시나리오별로 바꾼다.

## 불확실성 요인

| 요인 | 종류 |
|---|---|
| 기상 | 연속 |
| 전기화학 파라미터 | 연속 |
| 기작 선택 | 이산 |
| 수명 시점 | 시나리오 |

**Sobol 지수**로 수소 생산량 분산과 생산 0 확률에 대한 기여를 비교한다([`../../07-numerics/03-uncertainty-propagation.md`](../../07-numerics/03-uncertainty-propagation.md)).

## 구현 순서

| 순서 | 내용 | 필요 도구 | 난이도 |
|---|---|---|---|
| 1 | 분리기 물질수지를 기준 모델에 추가, 생산 0 확률 재계산 | scipy `solve_ivp` | 하 |
| 2 | 막 박화 되먹임, 수명 시나리오별 분포 | 해석해 + 문헌 FER | 중 |
| 3 | 2단계 기작, 기작 선택을 불확실성 요인으로 포함 | scipy `least_squares` | 중 |
| 4 | 촉매층 경계값 문제 | scipy `solve_bvp` | 중상 |
| 5 | 통합 분산 분해(기상·파라미터·기작·수명) | SALib | 중 |
| 6 | EIS·DRT (포텐시오스탯 사용 시) | impedance.py, pyDRTtools | 상 |
