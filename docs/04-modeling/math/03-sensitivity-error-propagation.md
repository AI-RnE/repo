# 전력 예측 오차의 영향: 민감도와 오차 전파

- 민감도: $\dfrac{dH}{dP}=f'(P)$
- 탄력성: $\varepsilon(P)=\dfrac{P\,f'(P)}{f(P)}$. 1보다 크면 전력의 상대 변화보다 수소 생산량의 상대 변화가 크다. 전력 오차율과 수소 오차율을 같다고 둘 수 없는 이유다.
- 2차 오차 전파: $f(P+\Delta P)\approx f(P)+f'(P)\Delta P+\tfrac12 f''(P)(\Delta P)^2$. $f''$의 부호(볼록/오목)에 따라 같은 예측 오차의 영향이 전력 구간별로 달라진다.
- 연구 질문 "정효율 가정이 얼마나 왜곡하는가"와 직접 연결된다.
