# 핵심 탐구 4가지와 단계별 정리

| # | 주제 | 핵심 식 |
|---|---|---|
| 1 | 비선형 함수 모델링 | $P=N_{\mathrm{cell}}V(I)I$ |
| 2 | 미분을 이용한 민감도·곡률 분석 | $\dfrac{dH}{dP},\;\dfrac{d^2H}{dP^2}$ |
| 3 | 확률분포의 비선형 변환 | $E[f(P)]\neq f(E[P])$ |
| 4 | 구간별 선형 근사와 최적화 | $f(P)\approx a_iP+b_i$ |

## 연구 단계별 정리

| 연구 단계 | 수학적 역할 | 관련 분야 |
|---|---|---|
| 발전량 예측 | 발전량 확률분포 분석 | 확률·통계 |
| 전기분해 모델 | 전력과 전류의 비선형 관계 | 함수·방정식 |
| 전류 계산 | 비선형 방정식의 수치 해법 | 수치해석 |
| 오차 분석 | 발전량 오차의 영향 | 미분·오차 분석 |
| 불확실성 전파 | 발전량 분포 → 수소 생산량 분포 | 확률론 |
| 예측 구간 | 구간의 신뢰도 분석 | 통계적 추론 |
| 선형 근사 | 비선형 모델을 구간별 직선으로 근사 | 함수 근사·수치해석 |
| 시스템 최적화 | 생산·저장 최적 운영 | 최적화 이론 |
