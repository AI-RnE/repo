# 실험 장치 구성

수조는 두 가지 역할을 한다. **항온수조**로 셀 온도를 25~55 °C에서 고정하고, **수상치환 수조**로 생산 수소 부피를 재서 패러데이 효율을 구한다. 기준은 Albarghot 외(2016)의 2 V·1 A급 단일 PEM 셀 + 상압 탱크 구성이며, 이 논문은 모델과 실험에서 모두 약 7.345 mL/(min·A)의 수소 생산을 보고했다.

## 장치 구성

| 구성 | 사양(권장) | 용도 |
|---|---|---|
| 소형 PEM 전해 셀 | 단일 셀, 정격 약 2 V·1 A, 활성면적 표기된 것 | 측정 대상 |
| 전원 | 정전류 가능한 프로그래머블 DC 전원 + 차단용 스위치(MOSFET) | 전류 계단·프로파일 인가 |
| 전압·전류 측정 | 셀 단자에서 4선식 전압 감지, 션트저항(0.1 Ω, ±0.1 %) + DAQ 1 Hz 이상, 전류 차단 기록용 오실로스코프(1 MS/s 이상) | 분극곡선, 계단응답 |
| 항온수조 | ±0.5 °C 제어, 셀 방수 처리 또는 수조 물을 셀 급수로 순환 | 온도 조건 4점 |
| 수상치환 수조 | 거꾸로 세운 눈금 실린더(50~100 mL, 눈금 1 mL 이하) + 물통 | 수소 부피 측정 |
| 온도·기압 | K형 열전대 2개(셀 표면, 수조), 기압계 | 열 모델, 기체 부피 보정 |
| 물 | 탈이온수(저항률 1 MΩ·cm 이상 권장) | 전해질 공급 |
