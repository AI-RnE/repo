# 모델 검증 기준

- **전압**: 35 °C 데이터를 학습에서 빼고(온도 홀드아웃) 예측 RMSE를 본다. 목표치는 반복 측정 산포의 2배 이내로 두고, 초기값 기준 15 mV로 잡는다.
- **수소**: E4에서 누적 수소량 예측 오차가 계량 불확도([계량·불확도](04-metering-and-uncertainty.md)) 안에 들어오는지 본다.
- **비교**: 같은 E4에서 정효율 모델(M0)과 부하의존 모델(M2)의 오차를 나란히 보고한다. 이 비교가 연구 질문의 실험적 근거가 된다.
- **한계**: 실험은 상압·25~55 °C이므로 압력 항과 80 °C 값은 문헌으로 보충한다.
