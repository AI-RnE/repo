# 실험 대장과 장치 관리

## 실험 대장

모든 실험은 한 줄씩 기록하고, 원자료 파일은 수정하지 않는다. 파일명은 `날짜_실험ID_온도_반복번호.csv`로 통일한다(예: `20261215_E1_45C_r2.csv`).

| 날짜·시각 | 실험 ID | 조건(T, 전류/프로파일) | 장비·교정일 | 원자료 파일 | E6 기준점 전압 | 이상사항 | 작성자 |
|---|---|---|---|---|---|---|---|
| | | | | | | | |

## 장치 관리

- [ ] 매 세션 전: 탈이온수 저항률 확인, 막이 마르지 않았는지 확인, 극성 확인
- [ ] 셀 제조사 정격 전압·전류를 넘지 않도록 전원 보호 한계 설정
- [ ] E6 기준점 전압이 초기값 대비 20 mV 이상 오르면 실험을 멈추고 원인을 기록(열화·접촉 불량)
- [ ] 수소는 소량만 수집하고 환기되는 곳에서 배출, 화기·스파크 금지
- [ ] 계측기 교정일을 대장에 기록, 분기별 재점검
- [ ] 실험 후: 셀 보관 조건(습윤 유지), 전원 차단
