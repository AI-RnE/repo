# 단계별 식별 절차 (S0~S6)

1. **S0 합성 데이터 복원 시험**: 실험 전에, 알려진 파라미터로 분극곡선을 만들고 예상 잡음(예: 3 mV)을 더한다. 추정기가 참값을 되찾는지 본다. 여기서 실패하는 파라미터는 실제 데이터로도 못 구한다.
2. **S1 온도별 적합**: 온도마다 ($\alpha_{an}$, $\log i_0$, $R_{ohm}$)을 scipy `least_squares`(트러스트 영역, 경계 제약)로 맞춘다. 다중 시작점 20개 또는 PSO로 전역해를 확인한다. PSO는 논문 재현용, `least_squares`는 공분산 행렬을 주므로 둘 다 쓴다.
3. **S2 α 고정 재적합**: 온도별 $\alpha$의 편차가 작으면 평균으로 고정하고 $i_0$·$R_{ohm}$만 다시 맞춘다. 자유도가 줄어 나머지 추정이 안정된다.
4. **S3 아레니우스 회귀**: $\ln i_0$와 $\ln R_{ohm}$을 $1/T$에 대해 선형 회귀해 $E_{exc}$, $E_{pro}$, 기준값을 구한다(논문 식 30–31).
5. **S4 열 파라미터**: E3 가열·냉각 곡선을 해석해(지수 응답)에 맞춰 $C_{th}R_{th}$를 구하고, 자연 냉각의 $\tau_{th}$로 교차 확인한다.
6. **S5 패러데이 효율**: E2의 $\eta_F(j)$에 [패러데이 효율 식](../04-modeling/02-cell-voltage-and-efficiency.md) 식을 맞춰 $N_{cross}$를 구한다. 저전류 점이 핵심이므로 계량 불확도를 가장 철저히 관리한다.
7. **S6 베이지안 결합 추정**: S1–S5 결과를 초기값으로, 모든 온도·실험을 한 번에 MCMC(emcee)로 추정한다. 사전분포는 [추정 대상 파라미터](01-parameters.md) 범위, 잡음은 반복 측정에서 구한 전류별 표준편차를 쓴다. 수렴은 $\hat R<1.01$, 유효 표본 수 1,000 이상으로 판정한다.
