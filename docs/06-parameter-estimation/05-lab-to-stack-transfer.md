# 실험실 셀 → 기준 스택 전이

- **구조**(식의 형태, $\alpha$의 온도 무관성, 아레니우스 형태)는 실험으로 검증한 것을 그대로 쓴다.
- **값**은 면적 기준(A/cm², Ω·cm²)으로 정규화하고, 스택 값은 Espinosa-López Table 3 등 문헌값을 사전분포 중심으로 둔다.
- **분산 크기**는 실험에서 얻은 사후분포의 상대 폭(예: $i_0$의 로그 표준편차)을 스택 사전분포에 옮겨 적용한다.
- **압력 항**(네른스트 식)과 30 bar 크로스오버는 실험으로 검증할 수 없으므로 문헌 범위를 민감도 분석으로 다룬다.
