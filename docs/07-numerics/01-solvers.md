# 미분방정식과 solver

수치해석의 원칙은 세 가지다. 시간 척도별로 문제를 분리한다. 모든 solver는 해석해와 비교해 검증한다. 불확실성 표본 수는 목표 정밀도에서 거꾸로 정한다.

## solver 표

| 문제 | 형태 | 풀이 | 검증 방법 |
|---|---|---|---|
| $P\to j$ 역산 | 단조 비선형 대수방정식 | scipy `brentq`, xtol 1e-10 | 대입 잔차 |
| 반복 계산 가속 | $H_2(P,T,\delta)$ 조회표 | `RegularGridInterpolator`(3차 스플라인) | 격자 사이 점에서 직접 계산과 상대오차 < 0.1 % |
| 열수지 $dT/dt$ | 비강성 ODE | `solve_ivp` RK45, rtol 1e-6 | 일정 전류에서 지수 해석해(논문 식 34) |
| 분리기 $dx/dt$ + 열 결합 | 척도 차이 큼(분~시간) | `solve_ivp` BDF 또는 Radau, events로 $x=2\,\%$ 도달 감지 | 정상상태 해 $x(t)=x_{ss}(1-e^{-t/\tau})$ |
| 막 박화 $d\delta/dt$ | 느린 상태(수천 시간) | 준정적: 하루 안 상수, 수명 시나리오로 변경 | $\delta^2$가 시간에 대해 선형인지 확인 |
| 촉매층 전위(선택) | 2점 경계값 문제 | `solve_bvp` | 저전류 극한에서 1/3 저항 근사와 일치 |

시간 간격과 허용오차는 절반으로 줄여 다시 돌렸을 때 하루 수소량이 0.1 % 이내로 바뀔 때까지 줄인다(수렴 시험).
