# 재생에너지 확률 예측과 시나리오 생성

- **모델**: 분위 회귀(기준선) → 분위 LSTM(기초 개념 PPT의 LSTM 확장). 출력은 시간대별 5~95 % 분위수다.
- **평가**: CRPS, pinball loss, PIT 히스토그램, 예측구간 포함률(예: 90 % 구간이 실제 88~92 %를 포함하는지).
- **시나리오**: 시간대별 분위수를 독립으로 뽑으면 하루 합계의 분산이 과소평가된다. 과거 예측 오차의 시간 상관을 가우시안 코퓰러로 추정해 24시간 경로를 한꺼번에 뽑는다.
- **데이터**: 기상청 관측·예보 자료와 태양광 발전량 공개자료. 어느 지점·기간을 쓸지는 열린 질문이다.
