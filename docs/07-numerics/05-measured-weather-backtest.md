# 실측 기상 백테스트 (검토 중인 확장)

가상 기상 분포 대신, **실측 기상 시계열**을 입력으로 쓰고 **시간축을 하루에서 몇 달~수 년으로 늘려** 같은 모델을 돌려 보는 확장이다. 연구 질문(정효율 가정이 수소 생산량 분포를 얼마나 왜곡하는가)을 "현실에서 확인한다"는 역할이다. 아직 설계 단계이며 데이터 확보 여부에 따라 범위가 바뀐다.

## 왜 하는가

- 가상 분포의 결과는 분포 가정과 시나리오 생성(코퓰러)에 기대고 있다. 실측 경로는 시간 상관을 이미 담고 있어 이 가정이 필요 없다.
- 시간축을 늘리면 막 박화(수천 시간 척도)를 "신품 / 수명 말기" 두 시나리오로 나누지 않고 **시간에 따라 진행**시킬 수 있다.
- 연간 계산에서야 계절 변동이 탱크 용량 산정에 들어온다.
- M0 대비 M2의 차이를 연간 누적 수소량과 월별 편향으로 보여 줄 수 있다.

## 두 입력 경로의 역할

| | 가상 기상 분포 (기존) | 실측 기상 경로 (추가) |
|---|---|---|
| 입력 | 분위수 예측 + 코퓰러로 만든 24시간 시나리오 | 관측 일사량·기온 시계열 |
| 시간축 | 하루 단위 시나리오 집합 | 수 개월~수 년, 시간 간격 1시간 |
| 막 두께 | 수명 시나리오로 고정 | 일 단위로 갱신 |
| 쓰임 | Sobol 분산 분해, 확률 최적화 입력 | 현실 확인, 계절·연도 변동, 용량 산정 검증 |
| 약점 | 분포 가정 의존 | 표본 수·연도 변동·지점 한정 |

**둘 다 유지한다.** 분산 분해는 요인을 독립적으로 흔들 수 있는 가상 분포가 필요하고, 실측 경로는 그 결과가 현실에서도 같은 방향인지 확인하는 용도다.

## 설계

1. **데이터**: 일사량, 기온(가능하면 운량·풍속), 가능하면 같은 지점·기간의 태양광 실측 발전량. 최소 2~3년을 목표로 한다(1년이면 경로 하나, 일 단위 약 365 표본이고 흐린 날 표본이 적다).
2. **일사량 → 출력 변환**: 단순 PV 모델로 $P_{PV}=P_{rated}\,\dfrac{G}{G_{STC}}\,[1+\gamma\,(T_{cell}-25\,^\circ\mathrm C)]$를 쓰고, 실측 발전량이 있으면 이것으로 계수를 보정·검증한다. 계수 값은 데이터로 정한다.
3. **시간 진행**: 시간 간격 1시간, 연 8,760 스텝. 열·분리기·탱크는 하루 안에서 적분하고, 막 두께는 하루가 끝날 때 갱신한다.

$$\delta_{d+1}^2=\delta_d^2-2\,c\,\varepsilon\,p_{H_2}\,\Delta t_{d}$$

   막 열화 계수 $c$의 불확실성이 시간축에서 증폭되므로 값의 범위를 요인으로 둔다([`../04-modeling/advanced-electrochem/01-membrane-degradation.md`](../04-modeling/advanced-electrochem/01-membrane-degradation.md)).
4. **같은 입력으로 병렬 계산**: M0, M2, M3를 같은 실측 경로에 돌려 비교한다.
5. **경험분포**: 일별 경로를 표본으로 삼아 일 수소량의 경험분포(평균, 표준편차, 생산 0 일 비율)를 만든다. 연도 단위 부트스트랩으로 연도 변동에 따른 신뢰구간을 붙인다.

## 비교 지표

| 지표 | 내용 |
|---|---|
| 연간 누적 수소량 차 | M2 대비 M0의 편향(%) |
| 월별 편향 | 계절별로 편향이 어떻게 달라지는가 |
| 생산 0 시간 비율, 생산 0 일 비율 | 최소부하 미달·정지로 생산이 없는 비율 (막 두께 진행에 따라 증가하는지) |
| 일 수소량 경험분포 | 평균, 표준편차, 분위수. 가상 분포 결과와 나란히 비교 |
| 탱크 저장량 경로와 최적 용량 | 계절 저장 효과 반영 |

실측 발전량이 있으면 확률 예측 자체도 평가한다(예측구간 포함률, CRPS, PIT. [`02-forecast-and-scenarios.md`](02-forecast-and-scenarios.md)).

## 한계

- 수소 쪽은 실측이 아니라 **모델 결과**다. "실측 기상으로 돌린 시뮬레이션"이라고 쓴다.
- 표본 수가 제한적이고 연도마다 다르다. 한 해의 결과를 일반화하지 않는다.
- 지점 하나의 자료이므로 지역 대표성은 따로 따진다.
- 실험은 상압·소형 셀이고 기준 스택은 30 bar이므로 압력 항은 문헌 범위로 민감도 분석한다([`../06-parameter-estimation/05-lab-to-stack-transfer.md`](../06-parameter-estimation/05-lab-to-stack-transfer.md)).

## 구현 순서

| 순서 | 내용 | 비고 |
|---|---|---|
| 1 | 데이터 확보와 품질 점검(결측, 야간 0, 이상치) | 지점·기간 결정이 선행 |
| 2 | 일사량 → 출력 변환 보정·검증 | 실측 발전량이 있을 때 |
| 3 | 연간 M0 vs M2 비교 (막 두께 고정) | 가장 먼저 나오는 결과 |
| 4 | 막 두께 일 단위 갱신 (M3) | 열화 계수 범위를 요인으로 |
| 5 | 탱크 저장량 경로와 용량별 비용 비교 | [`../08-optimization/01-milp-interface.md`](../08-optimization/01-milp-interface.md) |
| 6 | 가상 분포 결과와의 비교 | 방향·크기가 일치하는지 |

## 열린 질문

- 지점과 기간. 일사량 관측이 되는 가까운 지점이 있는지 먼저 확인해야 한다(확인 필요).
- 태양광 실측 발전량 공개자료를 같은 지점·기간으로 구할 수 있는가.
