# 확률 최적화 연결 형식

2024년 국문 논문의 계획 모델은 MILP이므로, 부하의존 효율도 선형 제약으로 넣을 수 있는 형태로 만든다.

- **수소–전력 곡선의 조각선형화**: 최소부하 이상에서 $H_2(P)$는 오목 곡선이다(고부하에서 효율 하락). 수소를 최대화하는 문제에서는 $h\le a_kP+b_k$ ($k=1\ldots K$) 형태의 선형 제약만으로 충분하다. 최소부하와 정지는 이진 변수 $u_t$와 $P_{\min}u_t\le P_t\le P_{\max}u_t$로 넣는다. 구간 수 $K$는 최대 근사오차 0.5 % 이내가 되는 최소값으로 정한다.
- **BOP 소비전력**(확장): 펌프·냉각·전력변환·대기전력을 고정항 + 비례항으로 두면 $P_{sys,t}=(1+b)P_{stack,t}+a\,u_t+P_{sb}(1-u_t)\le P_{RE,t}$로 선형이다. 실질 최소부하가 올라간다([`../04-modeling/04-balance-of-plant.md`](../04-modeling/04-balance-of-plant.md)).
- **시나리오 집합**: 몬테카를로 10,000개를 k-medoids 또는 fast-forward 축약으로 10~50개로 줄이고 각각 확률을 붙인다. 축약 전후 하루 수소량의 평균·분산·생산 0 확률 차이를 함께 보고한다.
- **정지 제약**: [상태 방정식](../04-modeling/03-state-equations.md) 분리기 결과를 "최소부하 아래 연속 $m$시간 이내" 같은 시간 결합 제약으로 바꿔 전달한다.
- **파일**: 아래 열을 가진 CSV(또는 Parquet). 신품·수명 말기 두 벌을 따로 만든다.

```csv
scenario,prob,hour,P_RE_kW,H2_const_kg,H2_var_kg,on,j_Acm2,eta_sys
1,0.042,0,0.0,0.000,0.000,0,0.00,0.000
1,0.042,12,812.5,15.47,14.31,1,1.62,0.71
```

위 숫자는 형식 예시이며 계산 결과가 아니다.

## 확인할 점

- 위 조각선형화는 $H_2(P)$가 최소부하 이상에서 **오목**이라는 전제에 기대고 있다. 저부하에서 전압 효율이 오히려 좋아지는 구간이 있으므로, M2 모델로 곡률($f''$)을 수치로 확인해야 한다. 오목이 아니면 구간마다 이진변수가 필요해진다.
- 근사 오차와 구간 수의 관계는 [`../04-modeling/math/06-piecewise-linear-approximation.md`](../04-modeling/math/06-piecewise-linear-approximation.md)를 따른다.
