# 일정과 위험요소

## 일정

약 15주(2026년 11월 말~2027년 3월 중순)로 잡고, 단계마다 통과 기준(G1~G3 등)을 둔다. 실험 장비 확보가 늦어지면 2단계만 밀리고, 1·4단계의 코드 작업은 문헌 파라미터로 먼저 진행한다.

G1을 통과하지 못한 파라미터는 실험 전에 고정값으로 돌리고, G3를 넘지 못하면 [모델 선택](../06-parameter-estimation/04-model-selection.md)으로 돌아간다.

> 단계별 일정표와 G1~G3 통과 기준의 정의는 원문 붙여넣기에 빠져 있어 아직 적지 못했다. 보완 필요.

## 위험요소와 대응

| 위험 | 영향 | 대응 |
|---|---|---|
| 전류 차단 측정의 배선 인덕턴스·잡음 | $R_{ohm}$ 과대·과소 추정 | 배선을 짧게, 차단 직후 수 µs 링잉 구간은 빼고 외삽, 분극곡선 적합값과 대조 |
| 교육용 셀의 활성면적·막 사양 미공개 | 면적 기준 정규화 불가 | 구매 전 사양 확인, 불가하면 셀 단위 값으로만 비교 |
| 눈금 판독 오차가 저전류 $\eta_F$를 가림 | 크로스오버 추정 불가 | 수집 시간 연장, 더 가는 눈금 실린더·뷰렛 사용 |
| 실험 도중 셀 열화 | 온도별 데이터가 서로 다른 상태에서 측정됨 | E6 기준점으로 드리프트 보정, 온도 순서 무작위화 |
| 실험 조건(상압)과 기준 스택(30 bar)의 차이 | 압력 항 미검증 | 문헌 범위로 민감도 분석, 보고서에 한계 명시 |
