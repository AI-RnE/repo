# 열린 질문

확인 방법과 우선순위를 붙인 전체 목록은 [`03-verification-and-risks.md`](03-verification-and-risks.md).

- 연구 계획서 4.3절(기준 모델)의 파라미터 표가 이번 자료에 없어, [추정 대상 파라미터](../06-parameter-estimation/01-parameters.md) 사전 범위는 Espinosa-López 외(2018) 기준으로만 적었다.
- 실험에 쓸 셀 모델과 항온수조 보유 여부는 아직 정해지지 않았다.
- 기상·발전량 데이터의 지점과 기간을 정해야 한다. 실측 기상 백테스트([`../07-numerics/05-measured-weather-backtest.md`](../07-numerics/05-measured-weather-backtest.md))를 하려면 일사량 관측이 있는 가까운 지점과 2~3년치 자료가 필요하다.
- 태양광 실측 발전량 공개자료를 같은 지점·기간으로 구할 수 있는지 확인해야 한다.
- 가상 분포 결과와 실측 경로 결과가 어긋날 때 무엇을 기준으로 삼을지 정해야 한다.
