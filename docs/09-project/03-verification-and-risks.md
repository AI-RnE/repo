# 확인 필요 사항과 위험요소 모음

문서 곳곳에 흩어진 "확인 필요", 가정, 위험을 한 곳에 모았다. 우선순위는 **제안**이며, 상태 칸은 진행하면서 채운다. 일정 중심의 위험표는 [`01-schedule-and-risks.md`](01-schedule-and-risks.md), 열린 질문은 [`02-open-questions.md`](02-open-questions.md).

## 1. 데이터와 자료

| # | 항목 | 이유·영향 | 확인 방법 | 우선순위 | 상태 |
|---|---|---|---|---|---|
| D1 | 기상·발전량 데이터의 지점과 기간 미정 | 시나리오와 실측 백테스트 모두의 입력. 정해져야 일사량→출력 변환을 보정할 수 있다 | 일사량 관측이 있는 가까운 지점 조회 | 높음 | 미확인 |
| D2 | 일사량 관측이 되는 지점이 있는가 | 없으면 운량 등으로 대체해야 하고 정확도가 떨어진다 | 기상 자료 제공처에서 관측 항목 확인 | 높음 | 미확인 |
| D3 | 태양광 실측 발전량을 같은 지점·기간으로 구할 수 있는가 | 변환 모델 검증과 확률 예측 평가에 필요 | 공개자료 조회 | 중간 | 미확인 |
| D4 | 실측 자료가 1년이면 경로 하나(약 365 표본), 흐린 날 표본 적음 | 연도 변동을 일반화할 위험 | 2~3년치 확보, 연도 부트스트랩 | 중간 | 미확인 |
| D5 | 연구 계획서 4.3절(기준 모델)의 파라미터 표가 자료에 없음 | 사전 범위를 Espinosa-López 기준으로만 적었다 | 원문 계획서에서 표 확보 | 높음 | 미확인 |
| D6 | $E_{exc}$, $E_{pro}$ 사전 범위가 "문헌 조사 필요"로 비어 있음 | S3 아레니우스 회귀의 사전분포가 없다 | 문헌 조사 | 중간 | 미확인 |
| D7 | 막 열화 계수 $c$, FER 문헌값의 불확실성 | 시간축을 늘릴수록 영향이 커진다 | 문헌 FER·운전 압력 자료 정리, 범위를 요인으로 | 중간 | 미확인 |

## 3. 모델·가정

| # | 항목 | 이유·영향 | 확인 방법 | 우선순위 | 상태 |
|---|---|---|---|---|---|
| M1 | 영향 크기(23 %→35 %, 6분~2시간, 45 mV 등)는 가상 기상 분포·기준 모델 가정의 계산값 | 실측 전에는 결론이 아니라 설계 근거 | 실험·실측 기상으로 재검증 | 높음 | 인지함 |
| M2 | $H_2(P)$가 최소부하 이상에서 오목이라는 가정 | 틀리면 조각선형화에 이진변수가 필요하고 MILP가 무거워진다 | M2 모델로 $f''$ 수치 확인 ([`../08-optimization/01-milp-interface.md`](../08-optimization/01-milp-interface.md)) | 높음 | 미확인 |
| M3 | 압력 항(네른스트)과 30 bar 크로스오버는 실험으로 검증 불가 | 기준 스택 결과가 문헌 의존 | 문헌 범위로 민감도 분석, 한계 명시 | 중간 | 계획됨 |
| M4 | 단일 전달계수 vs 2단계 기작은 중간 전류 자료로 구별 불가 | 고·저부하 외삽 오차 | 이산 불확실성 요인으로 포함, 가능하면 EIS·DRT | 중간 | 계획됨 |
| M5 | $\alpha$와 $i_0$ 강한 상관 (식별성) | 추정값이 불안정 | S0 합성 데이터 시험, 상관 행렬, 필요 시 $\alpha$ 고정 | 높음 | 계획됨 |
| M6 | 연구 질문의 둘째 항목은 원문에 없어 문서 구성에 맞춰 정리함 | 연구 질문 정의 불일치 가능 | 계획서 원문과 대조 | 낮음 | 미확인 |
| M7 | 실측 경로와 가상 분포 결과가 어긋날 때 기준 미정 | 결론의 근거가 흔들림 | 사전에 비교 기준 정의 | 중간 | 미정 |
| M8 | 일사량→출력 변환 계수는 데이터로 정해야 함 | 변환 오차가 수소 오차로 전파 | 실측 발전량으로 보정·검증 | 중간 | 미정 |
| M9 | BOP(펌프·냉각·전력변환·대기전력) 값의 출처 | 규모·설계 의존, 소형 셀 실험으로 검증 불가 | 문헌·제조사 자료로 범위 설정, 불확실성 요인으로 포함 ([`../04-modeling/04-balance-of-plant.md`](../04-modeling/04-balance-of-plant.md)) | 중간 | 미확인 |
| M10 | 효율 정의(스택 vs 시스템, HHV 기준) 혼용 | M0와 비교 시 기준이 섞이면 편향이 왜곡됨 | 결과 표마다 기준 명시 | 중간 | 계획됨 |
