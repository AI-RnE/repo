# 수학적 모델링 설계

태양광 발전량의 불확실성이 수소 생산량으로 어떻게 전달되는지 수학적으로 다루는 부분이다. 핵심은 발전량을 **하나의 값이 아니라 확률분포**로 보고, 전기분해 장치의 **비선형 응답**을 통과시킨다는 점이다.

```
기상 W ─▶ 발전량 분포 P ─▶ 전류 I (비선형 방정식) ─▶ 수소 H = f(P) ─▶ 분포·구간 ─▶ 구간별 선형 근사 ─▶ MILP
```

## 1. 태양광 발전량의 확률적 예측

- 발전량을 확률변수로 두고 기상 조건에 따른 분포를 분석한다: $P \sim f_P(p \mid W)$
- 맑은 날, 구름 변동이 있는 날, 흐린 날의 분포를 비교한다. 평균이 비슷해도 구름 변동이 크면 분산이 더 크다. 평균 $E[P]$와 분산 $\mathrm{Var}(P)$로 불확실성을 정량화한다.
- 예측 오차는 MAE, RMSE로 보고, 기상 조건에 따라 오차 특성이 어떻게 달라지는지 분석한다.

$$\mathrm{MAE}=\frac1n\sum_{i=1}^n|P_i-\hat P_i|,\qquad \mathrm{RMSE}=\sqrt{\frac1n\sum_{i=1}^n(P_i-\hat P_i)^2}$$

## 2. 발전량과 수소 생산량의 관계 H = f(P)

기존 모델은 효율을 상수로 둔다.

$$H=\frac{\eta P}{\mathrm{HHV}_{H_2}}$$

이 연구는 효율을 전류·전압·온도의 함수로 두고 전압–전류 관계에서 출발한다.

$$V(I)=E_{\mathrm{rev}}+\eta_{\mathrm{act}}(I)+\eta_{\mathrm{ohm}}(I)+\eta_{\mathrm{other}}(I),\qquad P=N_{\mathrm{cell}}\,V(I)\,I$$

1. **전류 구하기**: 주어진 $P$에 대해 $g(I)=N_{\mathrm{cell}}V(I)I-P=0$을 푼다. 비선형이라 뉴턴–랩슨법을 쓴다.

$$I_{n+1}=I_n-\frac{N_{\mathrm{cell}}V(I_n)I_n-P}{N_{\mathrm{cell}}\left[V(I_n)+I_nV'(I_n)\right]}$$

2. **수소 생산량**: 패러데이 법칙으로 전류를 몰 생산 속도로 바꾼다.

$$\dot n_{H_2}=\frac{N_{\mathrm{cell}}\,\eta_F\,I}{2F}$$

3. 결과적으로 $H=f(P)$는 단순 비례가 아닌 **비선형 함수**다. $V(I)$의 구체적인 항은 선택한 전해조 모델에 따라 달라진다([`electrochem-model.md`](electrochem-model.md) 참고).

## 3. 전력 예측 오차의 영향 (민감도·오차 전파)

- 민감도: $\dfrac{dH}{dP}=f'(P)$
- 탄력성: $\varepsilon(P)=\dfrac{P\,f'(P)}{f(P)}$. 1보다 크면 전력의 상대 변화보다 수소 생산량의 상대 변화가 크다. 전력 오차율과 수소 오차율을 같다고 둘 수 없는 이유다.
- 2차 오차 전파: $f(P+\Delta P)\approx f(P)+f'(P)\Delta P+\tfrac12 f''(P)(\Delta P)^2$. $f''$의 부호(볼록/오목)에 따라 같은 예측 오차의 영향이 전력 구간별로 달라진다.
- 연구 질문 "정효율 가정이 얼마나 왜곡하는가"와 직접 연결된다.

## 4. 발전량 분포 → 수소 생산량 분포

$H=f(P)$이므로 $H$도 확률변수다. 일반적으로

$$E[f(P)]\neq f(E[P])$$

이므로 평균 발전량만 모델에 넣은 결과와, 분포를 반영해 평균낸 결과가 다르다.

- 2차 근사 (평균 $\mu_P$, 분산 $\sigma_P^2$):

$$E[f(P)]\approx f(\mu_P)+\tfrac12 f''(\mu_P)\,\sigma_P^2$$

  수소 생산량의 평균이 발전량 평균뿐 아니라 **분산과 곡률**에도 의존한다. 맑은 날과 구름 변동이 큰 날의 차이를 설명하는 데 쓴다.
- 몬테카를로: 분포에서 $P_1,\dots,P_N$을 뽑아 $H_i=f(P_i)$를 계산하고, 평균·분산·분위수를 구한다. 해석적으로 분포를 구하기 어려울 때 쓴다.

## 5. 예측 구간

- 특정 시간의 수소 생산량을 $H_t\in[H_{\mathrm{low}},H_{\mathrm{high}}]$ 구간으로 표현한다.
- 구간 폭, 실제값 포함률, 기상 조건별 불확실성, 신뢰도와 효율성을 비교한다.
- Conformal Prediction으로 포함률을 보정한다. 다만 전체 데이터에서 포함률이 높아도 **모든 기상 조건·전력 구간에서 같은 포함률이 보장되지는 않으므로** 조건별 보정 여부를 따져야 한다.

## 6. 구간별 선형 근사

최적화에는 선형 함수가 다루기 쉬우므로 $f$를 구간 $P_0<P_1<\dots<P_n$에서 직선으로 근사한다.

$$H(P)\approx a_iP+b_i,\qquad a_i=\frac{H(P_{i+1})-H(P_i)}{P_{i+1}-P_i},\quad b_i=H(P_i)-a_iP_i$$

- 근사 오차: $E_{\max}=\max_P|f(P)-\hat f(P)|$, $E_{\mathrm{mean}}=\frac1n\sum|f(P_i)-\hat f(P_i)|$
- 구간 수에 따른 정확도와 계산량의 관계를 분석해 **필요한 최소 구간 수**를 정한다.
- 구간이 $f$의 볼록·오목 성질을 어떻게 보존하는지 확인한다. 최소 가동 전력, 가동/정지 조건이 있으면 이진변수가 필요한 MILP가 된다.

## 7. 운영 최적화

$$\max\sum_{t=1}^T H_t\quad\text{s.t.}\quad 0\le P_{\mathrm{ELZ},t}\le P_{\max},\;\; P_{\mathrm{ELZ},t}\le P_{\mathrm{PV},t},\;\; H_t\approx\hat f(P_{\mathrm{ELZ},t})$$

저장탱크를 포함하면 질량 보존식을 추가한다.

$$S_t=S_{t-1}+H_{\mathrm{prod},t}-H_{\mathrm{demand},t},\qquad 0\le S_t\le S_{\max}$$

최소 작동 전력, 가동 여부, 시동·정지 조건은 추가 제약으로 넣는다.

## 8. 핵심 탐구 4가지

| # | 주제 | 핵심 식 |
|---|---|---|
| 1 | 비선형 함수 모델링 | $P=N_{\mathrm{cell}}V(I)I$ |
| 2 | 미분을 이용한 민감도·곡률 분석 | $\dfrac{dH}{dP},\;\dfrac{d^2H}{dP^2}$ |
| 3 | 확률분포의 비선형 변환 | $E[f(P)]\neq f(E[P])$ |
| 4 | 구간별 선형 근사와 최적화 | $f(P)\approx a_iP+b_i$ |

## 연구 단계별 정리

| 연구 단계 | 수학적 역할 | 관련 분야 |
|---|---|---|
| 발전량 예측 | 발전량 확률분포 분석 | 확률·통계 |
| 전기분해 모델 | 전력과 전류의 비선형 관계 | 함수·방정식 |
| 전류 계산 | 비선형 방정식의 수치 해법 | 수치해석 |
| 오차 분석 | 발전량 오차의 영향 | 미분·오차 분석 |
| 불확실성 전파 | 발전량 분포 → 수소 생산량 분포 | 확률론 |
| 예측 구간 | 구간의 신뢰도 분석 | 통계적 추론 |
| 선형 근사 | 비선형 모델을 구간별 직선으로 근사 | 함수 근사·수치해석 |
| 시스템 최적화 | 생산·저장 최적 운영 | 최적화 이론 |
